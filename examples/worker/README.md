# Whisper Worker - WebSocket Server

WebSocket сервер для стриминга результатов транскрипции аудио клиенту.

## Особенности

- **Однопоточная обработка запросов**: в одно время обрабатывается только одна WebSocket сессия
- **Полное использование GPU**: при обработке используется вся мощь GPU как в CLI
- **Загрузка модели в память**: модель загружается один раз при старте и хранится в памяти
- **Прием аудио через WebSocket**: аудио файлы (WAV/MP3) загружаются напрямую через WebSocket, а не из файловой системы
- **Стриминг результатов**: результаты транскрипции отправляются клиенту в реальном времени по мере обработки

## Сборка

```bash
mkdir build
cd build
cmake ..
make whisper-worker
```

## Использование

```bash
./whisper-worker [опции]
```

### Опции

- `-m, --model FILE` - Путь к файлу модели (по умолчанию: `models/ggml-base.bin` - мультиязычная)
- `-t, --threads N` - Количество потоков (по умолчанию: автоматически)
- `-p, --processors N` - Количество процессоров для параллельной обработки (по умолчанию: 1)
- `-l, --language LANG` - Язык (по умолчанию: `auto` - автоопределение)
- `-tr, --translate` - Переводить на английский
- `-nt, --no-timestamps` - Не включать временные метки
- `-v, --verbose` - Подробный вывод

### Пример

```bash
./whisper-worker -m models/ggml-base.en.bin -t 4
```

Сервер запустится на порту 8765.

## Протокол WebSocket

### Подключение

Клиент подключается к `ws://localhost:8765` и выполняет WebSocket handshake.

### Отправка аудио

1. Клиент отправляет аудио данные как **binary frames** через WebSocket
2. После завершения отправки клиент отправляет текстовое сообщение `"process"` или `"ready"` для начала обработки

### Получение результатов

Сервер отправляет результаты в формате JSON, по одному сообщению на сегмент. После завершения обработки сервер отправляет сообщение `{"type":"complete"}`, после которого клиент должен закрыть соединение:

```json
{"type":"segment","index":0,"text":"Hello world","start":0.0,"end":1.5,"progress":15.3,"eta":45.2}
```

Поля в сообщении сегмента:
- `type`: всегда "segment"
- `index`: порядковый номер сегмента
- `text`: транскрибированный текст
- `start`: начальное время в секундах (если timestamps включены)
- `end`: конечное время в секундах (если timestamps включены)
- `progress`: прогресс обработки в процентах (0-100), рассчитывается по времени последнего сегмента относительно общей длины аудио
- `eta`: оставшееся время обработки в секундах (рассчитывается динамически на основе текущей скорости обработки)
- `speaker`: идентификатор спикера (если diarization включена)

Также могут отправляться сообщения о статусе:

```json
{"type":"status","message":"Processing audio..."}
{"type":"complete"}
{"type":"error","message":"Error description"}
```

### Закрытие соединения

Клиент может отправить текстовое сообщение `"close"` для закрытия соединения, или просто закрыть WebSocket соединение.

## Клиенты

### Ruby клиент

В комплекте поставляется Ruby клиент (`client.rb`), который можно использовать для отправки аудио файлов на сервер.

#### Установка зависимостей

С использованием Bundler (рекомендуется):

```bash
bundle install
```

Или вручную:

```bash
gem install websocket-client-simple json
```

#### Использование

С использованием Bundler:

```bash
bundle exec ruby client.rb [опции] <файл>
```

Или напрямую:

```bash
ruby client.rb [опции] <файл>
```

Опции:
- `-h, --host HOST` - Хост сервера (по умолчанию: localhost)
- `-p, --port PORT` - Порт сервера (по умолчанию: 8765)
- `--help` - Показать справку

#### Пример

```bash
ruby client.rb audio.wav
ruby client.rb -h 192.168.1.100 -p 8765 audio.mp3
```

### Пример клиента (JavaScript)

```javascript
const ws = new WebSocket('ws://localhost:8765');

ws.onopen = () => {
    // Отправить аудио файл
    const audioFile = new Uint8Array(/* audio data */);
    ws.send(audioFile);
    
    // Начать обработку
    ws.send('process');
};

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.type === 'segment') {
        console.log(`[${data.start}s-${data.end}s] ${data.text}`);
    } else if (data.type === 'complete') {
        console.log('Processing complete');
    } else if (data.type === 'error') {
        console.error('Error:', data.message);
    }
};
```

## Примечания

- Сервер обрабатывает только одно соединение за раз
- Модель загружается в память при старте и остается там до завершения работы сервера
- Поддерживаются форматы WAV и MP3 (если скомпилировано с поддержкой FFmpeg)
- Аудио декодируется в памяти без сохранения во временные файлы (если возможно)
