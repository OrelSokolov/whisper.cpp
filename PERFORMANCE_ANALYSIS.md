# Анализ производительности RX 6600 vs 680M

## Наблюдаемые результаты:

- **680M**: 7x realtime factor
- **RX 6600**: 11.70x realtime factor
- **Разница**: 1.67x (RX 6600 быстрее)

## Теоретическая разница:

- **680M**: 12 CUs
- **RX 6600**: 28 CUs
- **Ожидаемая разница**: 2.3x (28/12)

## Почему реальная разница меньше ожидаемой?

### Возможные причины:

1. **Узкие места не связанные с GPU:**
   - CPU подготовка данных
   - Декодирование аудио
   - Передача данных CPU↔GPU
   - Обработка результатов

2. **Память:**
   - RX 6600: GDDR6, но может быть недозагружена
   - 680M: системная RAM, но может быть быстрее в некоторых случаях

3. **Архитектурные оптимизации:**
   - 680M может иметь лучшие оптимизации для некоторых операций
   - RX 6600 может не использовать все 28 CUs эффективно

4. **Термальное троттлинг:**
   - RX 6600 может перегреваться и снижать частоту
   - Проверьте температуру GPU во время работы

5. **Настройки драйвера:**
   - Режим энергосбережения
   - Неоптимальные настройки RADV

## Что проверить:

1. **Температура GPU:**
   ```bash
   watch -n 1 sensors
   # или
   radeontop -d /dev/dri/card1 -l 1
   ```

2. **Загрузка GPU:**
   ```bash
   radeontop -d /dev/dri/card1
   # Должна быть близка к 100% во время обработки
   ```

3. **Частота GPU:**
   ```bash
   cat /sys/class/drm/card1/device/hwmon/hwmon*/freq1_input
   # Должна быть близка к максимальной (~2.4 GHz)
   ```

4. **Память GPU:**
   ```bash
   cat /sys/class/drm/card1/device/mem_info_vram_total
   cat /sys/class/drm/card1/device/mem_info_vram_used
   ```

## Возможные оптимизации:

1. **Проверьте режим производительности:**
   ```bash
   # Для AMD GPU через sysfs
   echo high > /sys/class/drm/card1/device/power_dpm_force_performance_level
   ```

2. **Увеличьте лимит энергопотребления (если возможно):**
   ```bash
   # Проверьте доступные настройки
   ls /sys/class/drm/card1/device/hwmon/hwmon*/
   ```

3. **Отключите PowerPlay (если тестируете):**
   ```bash
   # Через параметры ядра (требует перезагрузки)
   # amdgpu.ppfeaturemask=0xffffffff
   ```

## Вывод:

Разница в 1.67x вместо ожидаемых 2.3x может быть из-за:
- Узких мест не связанных с GPU вычислениями
- Неполной загрузки всех 28 CUs
- Термального троттлинга
- Неоптимальной конфигурации драйвера

Но даже 1.67x разница - это значительное улучшение для большой модели!
